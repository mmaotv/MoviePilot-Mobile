## 登录页服务器地址输入框改造
- **问题1**：`login.serverUrl`、`login.serverHistory`、`login.serverUrlRequired`、`login.credentialsRequired` 这几个 i18n key 在三个语言文件中均不存在，导致输入框标题始终显示英文 fallback，不随语言切换而变化
- **问题2**：服务器地址输入框要求用户输入完整 URL（含 http:// 前缀），体验不佳
- **修改内容**：
  1. 三个语言文件（zh-CN / zh-TW / en-US）均添加了 `login.serverUrl`、`login.serverHistory`、`login.serverUrlRequired`、`login.credentialsRequired` 翻译 key
  2. `login.vue` 新增 `detectedProtocol` computed：根据端口（443/8443 → https，其他 → http）自动识别协议，并用 Vuetify VTextField 的 `:prefix` 属性实时显示在输入框前
  3. 输入框 placeholder 改为 `192.168.1.100:3001`（纯域名/IP+端口格式）
  4. 新增 `stripProtocol()` 工具函数，历史记录显示时去掉协议前缀
  5. `login()` 函数改用 `detectedProtocol` 拼接完整 URL，去掉所有硬编码英文 fallback
